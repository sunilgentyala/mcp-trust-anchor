Validation checks (mcp_validator.py)
1. Signature verify (ES256)
2. Envelope expiry (TTL)
3. Trust level ≥ tool minimum
4. SHA-256 payload digest match
Trust level policy
1 PUBLIC → external web, feeds
2 INTERNAL → internal services
3 CONFIDENTIAL → restricted DBs
4 RESTRICTED → regulated data
