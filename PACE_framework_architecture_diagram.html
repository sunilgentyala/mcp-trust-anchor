Inter-Pillar Data Flows
P → A Intelligence Feed
Honeypot telemetry from ANH feeds SAAP for adversary signature correlation and attribution confidence scoring.
A → P Prioritized Actions
SAAP threat assessment triggers Tier 1 autonomous actions and surfaces Tier 2 recommendations with attribution probability.
C → P Terrain Priority
CIKR-MRT-C MDI scores define which assets receive highest ANH protection priority and pre-position DSCA authorities.
A → E EADM Assessment
SAAP attribution output informs EADM category — higher attribution confidence enables more precise deterrence communication.
P → E Action Logging
Every ANH action triggers EADM classification. Amber+ auto-logged to NSC crisis repository with timestamp and authority.
E → All Escalation Brake
EADM Black-category detection halts all automated processing and elevates to human deliberation — no autonomous escalation.

Diplomatic record exists; escalation managed proactively
Policy & Legal Architecture

Doctrine Change Required

Revise USCYBERCOM OG 3-2 — add pre-authorized autonomous defensive action category. Extend existing self-defense provisions.

Legislative Action Required

Pre-Crisis Civilian-Military Cyber Defense Authority (PCCDA) — standing DoD/CISA joint planning authority via Executive Order or NDAA.

CYBERCOM 2.0 Force Structure

New Cyber-Physical Protection Element (CPPE) embedded in CPTs with distinct ICS/OT authorities and CIKR-MRT-C training.
